Catalinas Design System

Single source: tokens.json + spec/*.json → Web CSS/JS · React · Qt QSS/Python · Flutter · Tailwind · Flat JSON. Los componentes nunca hardcodean valores: solo var(--cat-*). Severidad con icono líder, nunca franjas laterales. Ejemplo completo armado solo con el sistema: examples/kittydrive.html

Tokens

Colores del sistema (los semánticos derivan en runtime). 144 tokens totales.

Derivación de accent

El accent es un token semántico. En producción viene del hue dominante del wallpaper; acá lo movés a mano y todo el sistema reacciona.

hue: 215°

Theming: fuentes e iconos

Fuentes: override de --cat-font-family-ui (cargá la webfont que quieras). Iconos: data-cat-icon + CatalinasIcons.use(provider).
